# Number Nine logo

The mark is a 9 whose tail is a red chili pepper. The 9 is for Number Nine, and the pepper for Number Nine's "Pepper"
co-processor graphics boards (1986–1990), which the driver is named after. The bowl is woven in the Plaid tartan.
